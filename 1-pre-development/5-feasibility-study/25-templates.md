## 25 – Templates for Feasibility Studies

This file provides **markdown templates** to structure Feasibility work.

We include:

- A. Feasibility charter
- B. Option assessment table
- C. Feasibility summary

---

### A. Feasibility Charter Template

```markdown
# Feasibility Charter – <Initiative Name>

## 1. Context
- Problem(s):
  - <Summary / links>
- Business case:
  - <Link and key numbers>
- Strategic objectives:
  - <List>

## 2. Scope of Feasibility
- In scope:
  - <Systems, processes, segments, geographies>
- Out of scope:
  - <Items for later phases>

## 3. Key Questions
- Q1: <e.g., Can we support real-time decisions with current platforms?>
- Q2: <e.g., Are we allowed to fully automate approvals for segment X?>
- Q3: ...

## 4. Timebox & Deliverables
- Timeframe:
  - <Start and end dates>
- Deliverables:
  - Feasibility summary,
  - Risk register & constraint log,
  - Recommended option(s).

## 5. Team
- Architecture lead:
- Product manager:
- Business/ops owner:
- Security:
- Legal/compliance:
- Risk:
- Data/BI:
- Platform/infra:

## 6. Governance Touchpoints
- Architecture board:
- Risk/compliance committees:
- Product/portfolio councils:
```

### B. Option Assessment Table Template

```markdown
# Option Assessment – <Initiative Name>

## Options Overview

| Option | Description                         | Notes                                |
|--------|-------------------------------------|--------------------------------------|
| A      | <e.g., Build internal engine>       |                                      |
| B      | <e.g., Buy vendor solution>         |                                      |
| C      | <e.g., Hybrid build+buy>           |                                      |

## Feasibility & Risk Comparison

| Dimension           | Option A | Option B | Option C | Comments                            |
|---------------------|---------|---------|---------|-------------------------------------|
| Technical complexity| Med     | High    | Med     |                                     |
| Operational impact  | Low     | Med     | High    |                                     |
| Security/privacy    | Low     | Med-High| Med     |                                     |
| Legal/regulatory    | Med     | Med     | Med     |                                     |
| Delivery risk       | Med-High| Med     | High    |                                     |
| Time to value       | Med     | Fast    | Med     |                                     |

## Summary of Pros/Cons

Option A – <Title>
- Pros:
  - <...>
- Cons:
  - <...>

Option B – <Title>
- Pros:
  - <...>
- Cons:
  - <...>

Option C – <Title>
- Pros:
  - <...>
- Cons:
  - <...>
```

### C. Feasibility Summary Template

```markdown
# Feasibility Summary – <Initiative Name>

## 1. Executive Summary
- Scope of Feasibility:
  - <What we assessed>
- Main conclusion:
  - <e.g., Option B is feasible with certain conditions>
- Key risks and constraints:
  - <Top 3–5>
- Recommendation:
  - <Recommended option and phasing>

## 2. Context
- Problem and objectives:
  - <Reference to earlier phases>
- Business case highlights:
  - <Key numbers or rationale>

## 3. Options Considered
- Option A:
  - <Short description>
- Option B:
  - <Short description>
- Option C:
  - <Short description>

## 4. Feasibility by Dimension (Preferred Option)

### Technical
- Summary:
  - <Key findings>
- Open issues:
  - <List>

### Operational
- Summary:
  - <Key findings>
- Open issues:
  - <List>

### Security & Privacy
- Summary:
  - <Key findings>
- Open issues:
  - <List>

### Legal & Regulatory
- Summary:
  - <Key findings>
- Open issues:
  - <List>

### Organizational / Change
- Summary:
  - <Key findings>
- Open issues:
  - <List>

## 5. Risks & Constraints
- Refer to:
  - <Link to risk register and constraint log>
- Highlight:
  - <Top risks and hard constraints>

## 6. Recommendations & Next Steps
- Recommended option and scope:
- Preconditions / enablers:
- Next actions:
  - <Actions, owners, timelines>
```
